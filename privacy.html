Privacy and data handling

Daily Email Monitor is a personal desktop email monitoring application. This statement describes its implemented data handling. Updated October 2, 2026.

Data accessed

With the account owner's authorization, the application reads inbox message identifiers, thread identifiers, sender details, subjects, timestamps, message bodies and mailbox links. It reads original message headers when creating a reply draft. Reply text is proposed for the owner to review. The sender account, recipients, subject, full reply text, confirmation time and sending result are stored locally to bind an explicit confirmation to one version and prevent duplicate sending. The bot also receives text requests from the bound private Telegram chat; requests, replies, preferences and reminders are stored locally for conversation and execution.

Use and storage

Message text, metadata, review decisions and progress are stored locally in SQLite to track new mail and avoid duplicate notifications. OAuth credentials and the Telegram bot token are protected using Windows DPAPI for the current Windows user. Message bodies (up to 12,000 characters per message) are read for scheduled review. Attachments are not downloaded; attachment names may be retained. The owner controls the local files and email account permissions.

Services receiving data

Authorized API requests are sent to Google or Microsoft to access the corresponding mailbox and create requested drafts or send separately confirmed replies. Reviewed summaries, reasons and suggested actions, together with account address, sender, subject and timestamp, is sent through Telegram to the owner's selected private chat. Selected email text, metadata and the owner's Telegram requests and recent conversation context are processed through the owner's configured Codex/OpenAI service for review and requested assistance, including accounts accessed through a connector. The bot accepts only the bound private chat and sends email only after a separate, explicit confirmation of a fully delivered reply preview. Confirmations expire after 30 minutes; changed text requires a new preview. Uncertain send results are checked rather than automatically resent. This application does not sell data, use it for advertising, or use Google user data to train generalized AI models. Google API data is used only for the email features described here, consistent with the Google API Services User Data Policy, including its Limited Use requirements.

Owner controls

The owner can stop the local Windows task and Codex schedules, revoke Google or Microsoft authorization, revoke the Telegram bot token, and remove local application data. Removing local files does not delete messages or drafts stored in the original mailbox, or notifications stored in Telegram. Those are managed through the corresponding service.

Website

This informational website has no login form, analytics scripts or application database. The hosting provider may maintain its own standard access logs.
