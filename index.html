Daily Email Monitor

A personal desktop application for checking independently connected email accounts twice each day and reviewing message content and sending selected, actionable summaries to the account owner's Telegram chat.

Mail is accessed using the account owner's authorization. The application records message identifiers to avoid repeated notifications and supports creating reply drafts in the original mailbox. The assistant can also send a reply in the original mailbox and thread after displaying the sender account, recipients, subject and full reply text, and receiving a separate, explicit confirmation from the owner in the bound private Telegram chat. Confirmation expires after 30 minutes; editing produces a new preview and invalidates the earlier confirmation.

The monitoring program runs on the owner's Windows computer. This website provides application information; it does not collect credentials, provide a mailbox login, or host the monitoring service.
